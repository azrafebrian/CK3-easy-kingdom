## Installation and Use

1. Go To https://github.com/azrafebrian/CK3-easy-kingdom/releases and find the latest version, and **download**.
2. Extract the downloaded .zip file.
3. Copy or move halfsade_easykingdom folder and halfsade_easykingdom.mod into \Documents\Paradox Interactive\Crusader Kings III\mod
4. Open the game launcher and add mod to a playset, and enable the mod. 
5. Play game with selected playset.

## About This Mod

### Features

1. A new found a new kingdom decision with less requirement on realm size or held duchies. Reducing it to a single duchy with a single county as minimum. Located in major decision, next to the original decision.
2. To balance it, increased decision cost to 2000 gold and 5000 prestige.

### Requirements

1. Have at least a single duchy title.
2. Decision cost 2000 gold and 5000 prestige.

### Limitations

1. Cooldown for 10 years, after decision is used.
2. AI will not able to do this decision.

### Additional Info

- Available in a game that has already started.
- The mod didn't change the original 'Found a New Kingdom' decision. This is a standalone decision mod.
